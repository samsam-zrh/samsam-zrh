## Projets en groupe

### [News Agents](https://github.com/adk783/Projet-News-Agents/blob/version-finale-v3/README.md) · 2026

On analyse des actualités financières par entreprise. J’ai travaillé sur le sentiment avec FinBERT, l’incertitude avec LoRA, et les agents de risque juridique et de fondamentaux avec TF-IDF/Ridge. [Ma branche](https://github.com/adk783/Projet-News-Agents/tree/samuel).

### [EYE Médicale](https://github.com/samsam-zrh/eye-medicale) · 2025

Un prototype étudiant qui décrit des images médicales avec CLIP et Gemma. Avec Lorenzo, j’ai travaillé sur le modèle, les données, le fine-tuning LoRA et les tests. Le modèle est relié à l’interface web par FastAPI.
