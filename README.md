## Projets perso

### [Mon climat — Daikin](https://github.com/samsam-zrh/daikin-local)

Une app pour contrôler mes clims sur le réseau local. Je suis parti d’une analyse de ONECTA et du protocole Daikin, puis j’ai fait une interface web en Python et une app iPhone en SwiftUI. On peut régler la température, le mode et la ventilation. Le dépôt contient aussi une démo pour essayer sans appareil.

`Python` · `JavaScript` · `Swift` · `SwiftUI`

### [Webtoon Lens](https://github.com/samsam-zrh/webtoon-lens-ios)

Un lecteur local pour traduire des pages de webtoon de l’anglais ou du chinois vers le français. J’utilise l’OCR Vision sur Mac, un modèle local et un glossaire par série. Le dépôt contient aussi le prototype iPhone en SwiftUI.

### [Dashboard RES2-6-9](https://github.com/samsam-zrh/enedis-res2-6-9-ai-dashboard)

Un projet sur des données Enedis : préparation des fichiers, détection des cas RS/RP, prévisions et affichage dans un dashboard Streamlit.
